# 整体报告梳理（第三级 LLM 处理）设计

日期：2026-08-14
状态：已获用户批准

## 背景

现有管线是逐段处理：原文 → 优化（术语纠错）→ 增强（提取报告内容/标记非报告）。分段输出缺乏全局组织：重复描述未去重、结论与所见混在一起、逐段列表不是一份可直接使用的报告。本次在管线末端增加**整体梳理**：会话结束时对全部增强后内容做一次第三级 LLM 处理，产出完整两段式妇产科超声报告。

## 已与用户确认的决策

1. **结构**：【超声所见】+【超声提示】两段式（结论性用语如"考虑/可能/建议"归入提示；无提示内容时只出所见）
2. **落地**：file 模式结束时终端打印整体报告，`--report` 文件内容改为整体报告（不再逐段）；realtime 停止（Ctrl+C/音频结束）时打印整体报告；text 模式不变
3. **冲突数值**：重复且一致的描述去重；数值不一致的重复测量**全部保留**（模型不替医生取舍）

## 改动范围

`llm.py`、`modes.py`、`eval_terms.py`。不动 `asr.py`（不加新参数）、`pipeline.py`。

### llm.py

新增 `FINAL_SYSTEM_PROMPT` 和 `finalize(self, text: str) -> str`（复用 `_run`，非流式）。prompt 要点：

- 输入：一次检查中提取的全部报告句子（已经过术语纠错和内容筛选）
- 组织为【超声所见】/【超声提示】两节
- **只使用输入中明确存在的医学内容，绝不补充、推测、编造输入中没有的医学事实**（针对已实测发现的臆造风险，见 2026-08-13 验证记录）
- 重复一致去重；数值不一致全部保留（如"内膜厚约 8mm，后测约 9mm"）
- 数值、单位、左右侧不得改动；只输出报告文本，无解释

### modes.py

- `run_file`：现有循环已收集 `report_lines`；转写结束后若 `report_lines` 非空，调用 `finalize("\n".join(report_lines))`，终端带分隔线打印整体报告；`--report` 文件写入整体报告文本。`report_lines` 为空时打印"未识别到报告内容"，不写文件（替代现有 0 行文件行为）
- `run_realtime`：`handle_segments` 接收 `emit_all` 返回值，把非非报告的 enhanced 收集到会话级列表；`finally` 中 VAD flush 之后、打印"已停止"之前做整体梳理并打印。`--no-enhance` / `--no-llm` 时无收集、不梳理
- `run_text`：完全不变

### eval_terms.py

新增 3 条整体梳理用例（FINAL_CASES）：
1. 含重复描述 + 结论句的输入 → 输出含两节标题、重复已去重、结论句在【超声提示】侧
2. 含不一致数值（8mm / 9mm）→ 两个数值都在输出中
3. 含闲聊残留词的输入 → 输出不含闲聊词（双保险，正常情况输入已被增强级过滤）

判定沿用 `_norm` 空白归一 + 子串检查。

## 成功标准

1. eval 原有 25 例保持全过 + 新增 3 例全过
2. 真实录音 B.WAV 实测：`--report` 输出结构正确的两段式报告，原 4 行报告内容无丢失、数值一致
3. A.WAV（纯闲聊）实测：提示"未识别到报告内容"，不写空文件

## 非目标（YAGNI）

- realtime 多患者会话切分（一个会话视为一个患者；连续检查需重启程序）
- text 模式的整体梳理
- 报告模板化（按早孕/肌瘤等病种套用固定模板）——等实际使用反馈
