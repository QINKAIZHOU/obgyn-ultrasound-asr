# 超声术语纠错增强设计（SYSTEM_PROMPT + 验证集）

日期：2026-08-13
状态：已获用户批准

## 背景

`llm.py` 的 `SYSTEM_PROMPT` 负责把 ASR 原始输出纠正为规范的超声医学书面用语。当前术语举例较简略（约 400 字），妇产科/乳腺科的同音错误覆盖不成体系。本次**系统性增强术语覆盖**（无具体案例驱动，防患于未然）。

## 范围

- 改：`llm.py` 中的 `SYSTEM_PROMPT` 字符串（仅此一处）
- 新增：`eval_terms.py` 验证脚本（仓库根目录）
- 不改：`pipeline.py`、`modes.py`、`asr.py` 的任何逻辑

## SYSTEM_PROMPT 新结构

```
角色与任务（保留现有定位）
术语库（分四组，核心词 + 典型同音错误对照）
 ├─ 妇科：子宫(子工)、子宫内膜(内幕)、肌瘤(机留)、囊肿(囊种)、畸胎瘤(几胎留)、
 │        盆腔积液、液性暗区(叶性暗区)、卵泡、黄体、多囊卵巢、腺肌症等
 ├─ 产科：孕囊(韵囊)、胎心(太心)、胎芽、胎盘(太盘)、羊水(杨水)、双顶径(双顶颈)、
 │        股骨长(骨股长)、脐血流(其血流)、NT、羊水指数、胎盘成熟度等
 ├─ 乳腺：结节(节节)、钙化(盖化)、导管扩张、纵横比、血流信号(流血信号)、
 │        BI-RADS 分级、腋窝淋巴结、弹性成像等
 └─ 通用超声：低/强/无回声、肾盂分离、胆囊息肉、甲状腺结节、TI-RADS 等
纠错规则（完整保留现有约束）
输出约束（只输出文本，无解释）
```

约束：

- 每科 20–40 个核心词，prompt 总长 ≤ 约 800 字（现约 400 字）
- 现有 6 条规则全部保留、不弱化：不改数值/单位/左右侧；不增删医学事实；保持句子数量与顺序；无错原样输出；只输出文本
- 同音对照仅作"示例"性质列举，不追求穷举

## 验证集（eval_terms.py）

约 20 条用例，直接调用 `UltrasoundOptimizer` 批量跑，打印对照表并汇总通过率：

| 类别 | 数量 | 输入 | 通过标准 |
|------|------|------|----------|
| 含错句 | ~12 | 人为写入同音错字的"ASR 原始输出" | 纠正为正确术语 |
| 无误句 | ~5 | 完全正确的句子 | 原样输出（防误伤） |
| 关键信息句 | ~3 | 含数值/单位/左右侧的句子 | 数值、单位、左右侧零改动 |

脚本始终评估代码中当前的 `SYSTEM_PROMPT`，不加任何开关。基线对比方式：**改 prompt 之前先跑一次记录基线，改完再跑一次**，人工对比两份对照表。

## 成功标准

1. 含错句纠错通过率较基线明显提升
2. 无误句 100% 原样输出；关键信息句数值/单位/左右侧零改动
3. prompt 总长 ≤ 约 800 字

## 非目标（YAGNI）

- 不上 ASR 热词（Contextual Paraformer）——无实际案例时性价比低，等真实错误案例出现再评估
- 不做自动化断言接入 CI——人工核对对照表即可
